## 🇬🇧 English

AudioLight Manager is a free and customizable Windows application that brings audio and screen brightness controls together in one place.

Developed with the help of artificial intelligence.

### ✨ Features

- 🔊 Master volume control.
- 🎚️ Individual application volume mixer.
- 🎧 Audio output selection for each application.
- ☀️ Monitor brightness control.
- 🌙 Software dimming for compatible screens and projectors.
- 🎮 Custom profiles for gaming, movies, music and more.
- 🎨 Customizable colors, themes and appearance.
- 🌍 English, Spanish and German languages.
- 📦 Portable application — no installation required.
- 💗 Completely free and ad-free.

### 📥 Download

Version 0.9.2 Beta — coming soon.

### 💻 System requirements

- Windows 11.
- Windows 10 compatibility has not been tested yet.
- Hardware brightness control depends on monitor compatibility.

### 🐞 Feedback

This application is currently in beta. Feedback, suggestions and bug reports are welcome!
